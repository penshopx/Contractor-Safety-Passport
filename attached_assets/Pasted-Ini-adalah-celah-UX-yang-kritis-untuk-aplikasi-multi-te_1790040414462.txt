Ini adalah **celah UX yang kritis** untuk aplikasi multi-tenant. Ketika owner tidak tahu *mengapa* suatu tindakan gagal, mereka akan:
1. Mencoba berulang kali (memperparah masalah)
2. Menghubungi support (beban operasional)
3. Menyerah dan meninggalkan aplikasi (churn)

Mari kita bangun sistem error handling yang **spesifik, actionable, dan traceable**.

---

## 1. Pemetaan Skenario Kegagalan

Berdasarkan operasi tim yang umum, berikut skenario kegagalan yang perlu ditangani:

### A. Perubahan Peran (Role Update)
| Skenario | Penyebab | Tindakan Owner |
|----------|----------|----------------|
| Target tidak ditemukan | Member sudah dihapus atau ID salah | Periksa daftar anggota terbaru |
| Peran tidak valid | Role yang dipilih tidak ada di sistem | Pilih role yang tersedia |
| Tidak bisa mengubah diri sendiri | Owner mencoba mengubah role sendiri | Tunjuk owner lain terlebih dahulu |
| Tidak bisa menurunkan role last owner | Hanya ada 1 owner dan ingin dijadikan member | Tunjuk owner baru dulu |
| Izin tidak cukup | User yang mengubah bukan owner | Hubungi owner organisasi |

### B. Pencabutan Anggota (Member Removal)
| Skenario | Penyebab | Tindakan Owner |
|----------|----------|----------------|
| Target tidak ditemukan | Member sudah dihapus | Periksa daftar anggota terbaru |
| Tidak bisa menghapus diri sendiri | Owner mencoba menghapus akun sendiri | Transfer ownership terlebih dahulu |
| Tidak bisa menghapus last owner | Hanya ada 1 owner | Tunjuk owner baru dulu |
| Member memiliki proyek aktif | Member sedang mengelola proyek yang berjalan | Transfer proyek ke member lain |
| Izin tidak cukup | User yang menghapus bukan owner | Hubungi owner organisasi |

### C. Pembatalan Undangan (Invitation Revocation)
| Skenario | Penyebab | Tindakan Owner |
|----------|----------|----------------|
| Undangan tidak ditemukan | Undangan sudah diterima/dibatalkan | Periksa status undangan |
| Undangan sudah diterima | Target sudah menjadi member | Tidak perlu dibatalkan |
| Undangan sudah kedaluwarsa | Undangan lewat dari masa berlaku | Kirim undangan baru |
| Izin tidak cukup | User yang membatalkan bukan owner | Hubungi owner organisasi |

## 3. Implementasi Handler dengan Error Spesifik

**Contoh: Handler Perubahan Role**
```typescript
// handlers/update-member-role.ts
async function updateMemberRole(
  organizationId: string,
  actorId: string,
  targetMemberId: string,
  newRole: string
) {
  // 1. Validasi actor adalah owner
  const actor = await prisma.organizationMember.findFirst({
    where: { organizationId, userId: actorId }
  });
  
  if (!actor || actor.role !== 'OWNER') {
    throw new TeamOperationError(TeamErrorCode.INSUFFICIENT_PERMISSIONS);
  }
  
  // 2. Validasi role baru valid
  if (!['OWNER', 'SAFETY_EXPERT', 'MEMBER'].includes(newRole)) {
    throw new TeamOperationError(TeamErrorCode.INVALID_ROLE, { providedRole: newRole });
  }
  
  // 3. Cari target member
  const target = await prisma.organizationMember.findFirst({
    where: { id: targetMemberId, organizationId }
  });
  
  if (!target) {
    throw new TeamOperationError(TeamErrorCode.MEMBER_NOT_FOUND, { targetMemberId });
  }
  
  // 4. Tidak bisa mengubah diri sendiri
  if (target.userId === actorId) {
    throw new TeamOperationError(TeamErrorCode.CANNOT_CHANGE_SELF_ROLE);
  }
  
  // 5. Jika mengubah owner menjadi non-owner, cek apakah ini last owner
  if (target.role === 'OWNER' && newRole !== 'OWNER') {
    const ownerCount = await prisma.organizationMember.count({
      where: { organizationId, role: 'OWNER' }
    });
    
    if (ownerCount === 1) {
      throw new TeamOperationError(TeamErrorCode.CANNOT_DOWNGRADE_LAST_OWNER);
    }
  }
  
  // 6. Lakukan perubahan
  return await prisma.organizationMember.update({
    where: { id: targetMemberId },
    data: { role: newRole, updatedAt: new Date() }
  });
}
```

**Contoh: Handler Pencabutan Anggota**
```typescript
// handlers/remove-member.ts
async function removeMember(
  organizationId: string,
  actorId: string,
  targetMemberId: string
) {
  // ... validasi actor adalah owner ...
  
  const target = await prisma.organizationMember.findFirst({
    where: { id: targetMemberId, organizationId }
  });
  
  if (!target) {
    throw new TeamOperationError(TeamErrorCode.MEMBER_NOT_FOUND);
  }
  
  // Tidak bisa menghapus diri sendiri
  if (target.userId === actorId) {
    throw new TeamOperationError(TeamErrorCode.CANNOT_REMOVE_SELF);
  }
  
  // Cek apakah last owner
  if (target.role === 'OWNER') {
    const ownerCount = await prisma.organizationMember.count({
      where: { organizationId, role: 'OWNER' }
    });
    
    if (ownerCount === 1) {
      throw new TeamOperationError(TeamErrorCode.CANNOT_REMOVE_LAST_OWNER);
    }
  }
  
  // Cek apakah memiliki proyek aktif
  const activeProjects = await prisma.project.count({
    where: { 
      organizationId,
      ownerId: target.userId,
      status: { in: ['ACTIVE', 'PLANNING'] }
    }
  });
  
  if (activeProjects > 0) {
    throw new TeamOperationError(TeamErrorCode.MEMBER_HAS_ACTIVE_PROJECTS, {
      activeProjectCount: activeProjects
    });
  }
  
  // Lakukan penghapusan
  return await prisma.organizationMember.delete({
    where: { id: targetMemberId }
  });
}
```

## 5. UI Feedback yang Actionable (Frontend)

**Komponen Toast/Alert yang Kaya Informasi:**
```typescript
// components/team-error-toast.tsx
import { toast } from 'sonner';
import { TeamErrorCode, teamErrorMessages } from '@/types/team-errors';

export function showTeamError(error: { code: TeamErrorCode; context?: any }) {
  const errorInfo = teamErrorMessages[error.code];
  
  if (!errorInfo) {
    toast.error('Terjadi kesalahan yang tidak diketahui');
    return;
  }
  
  toast.error(errorInfo.title, {
    description: (
      <div className="space-y-2">
        <p>{errorInfo.message}</p>
        {errorInfo.action && (
          <p className="text-sm font-medium text-muted-foreground">
            💡 {errorInfo.action}
          </p>
        )}
        {error.context?.activeProjectCount && (
          <p className="text-xs text-muted-foreground">
            Jumlah proyek aktif: {error.context.activeProjectCount}
          </p>
        )}
      </div>
    ),
    duration: 8000, // Lebih lama agar owner sempat baca
  });
}
```

```typescript
// pages/team.tsx
async function handleUpdateRole(memberId: string, newRole: string) {
  try {
    await api.put(`/team/members/${memberId}/role`, { role: newRole });
    toast.success('Role berhasil diubah');
    refetchMembers();
  } catch (error) {
    if (error.response?.data?.error) {
      showTeamError(error.response.data.error);
    } else {
      toast.error('Gagal mengubah role. Silakan coba lagi.');
    }
  }
}

async function handleRemoveMember(memberId: string) {
  if (!confirm('Yakin ingin menghapus anggota ini?')) return;
  
  try {
    await api.delete(`/team/members/${memberId}`);
    toast.success('Anggota berhasil dihapus');
    refetchMembers();
  } catch (error) {
    if (error.response?.data?.error) {
      showTeamError(error.response.data.error);
    } else {
      toast.error('Gagal menghapus anggota. Silakan coba lagi.');
    }
  }
}

async function handleRevokeInvitation(invitationId: string) {
  try {
    await api.delete(`/team/invitations/${invitationId}`);
    toast.success('Undangan berhasil dibatalkan');
    refetchInvitations();
  } catch (error) {
    if (error.response?.data?.error) {
      showTeamError(error.response.data.error);
    } else {
      toast.error('Gagal membatalkan undangan. Silakan coba lagi.');
    }
  }
}
```

**Test untuk Memastikan Error Spesifik Dikembalikan:**
```typescript
// tests/team-errors.test.ts
describe('Team Error Handling', () => {
  test('should return CANNOT_DOWNGRADE_LAST_OWNER when downgrading only owner', async () => {
    const org = await createOrganization();
    const owner = await addMember(org.id, 'OWNER');
    
    await expect(
      updateMemberRole(org.id, owner.userId, owner.id, 'MEMBER')
    ).rejects.toThrow(TeamOperationError);
    
    try {
      await updateMemberRole(org.id, owner.userId, owner.id, 'MEMBER');
    } catch (error) {
      expect(error).toBeInstanceOf(TeamOperationError);
      expect(error.code).toBe(TeamErrorCode.CANNOT_DOWNGRADE_LAST_OWNER);
    }
  });
  
  test('should return MEMBER_HAS_ACTIVE_PROJECTS when removing member with projects', async () => {
    const org = await createOrganization();
    const owner = await addMember(org.id, 'OWNER');
    const member = await addMember(org.id, 'MEMBER');
    await createProject(org.id, member.userId, 'ACTIVE');
    
    try {
      await removeMember(org.id, owner.userId, member.id);
    } catch (error) {
      expect(error.code).toBe(TeamErrorCode.MEMBER_HAS_ACTIVE_PROJECTS);
      expect(error.context.activeProjectCount).toBe(1);
    }
  });
  
  test('should return INVITATION_ALREADY_ACCEPTED when revoking accepted invitation', async () => {
    const org = await createOrganization();
    const owner = await addMember(org.id, 'OWNER');
    const invitation = await createInvitation(org.id, 'test@example.com');
    await acceptInvitation(invitation.id);
    
    try {
      await revokeInvitation(org.id, owner.userId, invitation.id);
    } catch (error) {
      expect(error.code).toBe(TeamErrorCode.INVITATION_ALREADY_ACCEPTED);
    }
  });
});
```

## 8. Rekomendasi Tambahan

**A. Logging untuk Debugging**
Setiap error yang dilempar harus di-log dengan konteks lengkap:
```typescript
logger.warn('Team operation failed', {
  errorCode: error.code,
  organizationId,
  actorId,
  targetMemberId,
  context: error.context,
  timestamp: new Date().toISOString()
});
```

**B. Analytics untuk UX Improvement**
Track error mana yang paling sering terjadi:
```typescript
analytics.track('team_operation_failed', {
  errorCode: error.code,
  operation: 'update_role' | 'remove_member' | 'revoke_invitation'
});
```
Jika `MEMBER_HAS_ACTIVE_PROJECTS` sering terjadi, pertimbangkan fitur "Transfer Proyek Massal".

**C. Help Center Integration**
Setiap error code bisa punya link ke dokumentasi:
