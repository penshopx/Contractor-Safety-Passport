### 🚀 Rencana Aksi Perbaikan (Sprint to Release)

#### PR 1: Keamanan Dasar & Stabilitas Startup (Prioritas Tertinggi)
**Tujuan:** Menghilangkan risiko migrasi liar dan pembajakan session.

1. **Hapus `db push` dari Startup Produksi**
   - **Tindakan:** Ubah skrip `start:production` di `package.json` API menjadi hanya: `"node dist/index.js"`.
   - **Konteks Replit:** Perubahan schema harus dilakukan secara manual melalui panel "Database" atau "Publish" di Replit, yang akan menampilkan diff dan meminta konfirmasi sebelum eksekusi.
   - **Verifikasi:** Restart API, pastikan tidak ada log migrasi, dan aplikasi tetap berjalan.

2. **Perketat CORS (Allowlist)**
   - **Tindakan:** Ganti `origin: true` dengan allowlist eksplisit.
   - **Snippet Kode:**
     ```typescript
     const allowedOrigins = process.env.NODE_ENV === 'production' 
       ? ['https://contractor-safety-passport.replit.app'] // Tambahkan custom domain nanti
       : ['http://localhost:5173', /https:\/\/.*\.replit\.dev$/]; // Izinkan preview Replit di dev

     app.use(cors({
       origin: function (origin, callback) {
         if (!origin) return callback(null, true); // Izinkan request tanpa origin (misal: mobile app, curl)
         const isAllowed = allowedOrigins.some(allowed => 
           typeof allowed === 'string' ? allowed === origin : allowed.test(origin)
         );
         if (isAllowed) {
           callback(null, true);
        } else {
           callback(new Error('Not allowed by CORS'));
         }
       },
       credentials: true,
     }));
     ```

3. **Implementasi Rate Limiting Dasar**
   - **Tindakan:** Gunakan `express-rate-limit` pada endpoint sensitif.
   - **Snippet Kode:**
     ```typescript
     import rateLimit from 'express-rate-limit';

     // Untuk endpoint publik/auth (misal: 100 req per 15 menit per IP)
     const apiLimiter = rateLimit({
       windowMs: 15 * 60 * 1000, 
       max: 100, 
       standardHeaders: true, 
       legacyHeaders: false,
       // Penting untuk Replit/Proxy: gunakan header X-Forwarded-For
       trustProxy: 1, 
       message: { error: 'Terlalu banyak permintaan, silakan coba lagi nanti.' }
     });

     // Terapkan pada router yang relevan
     app.use('/api/auth', apiLimiter);
     app.use('/api/invitations', apiLimiter);
     ```

#### PR 2: Keandalan Sistem (Reliability)
**Tujuan:** Memastikan sistem bisa pulih sendiri dan melaporkan status yang jujur.

1. **Health Check yang Bermakna**
   - **Tindakan:** Ubah `/api/healthz` untuk memverifikasi koneksi database.
   - **Snippet Kode:**
     ```typescript
     app.get('/api/healthz', async (req, res) => {
       try {
         // Query ringan dengan timeout pendek
         await Promise.race([
           db.execute('SELECT 1'),
           new Promise((_, reject) => setTimeout(() => reject(new Error('DB Timeout')), 2000))
         ]);
         res.status(200).json({ status: 'ok', database: 'connected' });
       } catch (error) {
         res.status(503).json({ status: 'error', database: 'disconnected' });
       }
     });
     ```

2. **Graceful Shutdown yang Benar**
   - **Tindakan:** Tangani `SIGTERM` untuk menutup server HTTP dengan anggun sebelum `process.exit()`.
   - **Snippet Kode:**
     ```typescript
     const server = app.listen(8080, () => console.log('API running'));

     const gracefulShutdown = async (signal: string) => {
       console.log(`\n${signal} diterima. Menutup server dengan aman...`);
       
       // 1. Berhenti menerima job baru (untuk worker Task #67)
       stopCompensationWorker(); 
       
       // 2. Tutup koneksi HTTP yang masuk
       server.close(async () => {
         console.log('HTTP server ditutup.');
         // 3. Tutup koneksi database
         await db.$client.end(); 
         console.log('Database disconnected.');
         process.exit(0);
       });

       // 4. Paksa keluar jika shutdown memakan waktu terlalu lama (> 10 detik)
       setTimeout(() => {
         console.error('Shutdown timeout, memaksa keluar...');
         process.exit(1);
       }, 10000).unref();
     };

     process.on('SIGTERM', () => gracefulShutdown('SIGTERM'));
     process.on('SIGINT', () => gracefulShutdown('SIGINT'));
     ```
