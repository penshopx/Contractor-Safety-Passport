## 1. Temuan TINGGI #1: Profil Terarsip Masih Bisa Diedit

Ini adalah **bug logika yang berbahaya**. Dalam dunia kepatuhan, arsip = beku. Jika arsip masih bisa diedit, maka integritas historis runtuh — Anda tidak bisa lagi membuktikan "dokumen apa yang berlaku pada tanggal X".

### Solusi: Defense in Depth (3 Lapis)

**Lapis 1 — Database Constraint:**
```sql
-- Tambahkan check constraint di level database
ALTER TABLE csms_profiles 
ADD CONSTRAINT prevent_edit_archived 
CHECK (NOT (archived = true AND locked = false));

-- Atau lebih eksplisit: buat trigger
CREATE OR REPLACE FUNCTION prevent_archived_update()
RETURNS TRIGGER AS $$
BEGIN
  IF OLD.archived = true AND NEW.archived = true THEN
    -- Izinkan hanya perubahan field tertentu (metadata restore)
    IF NEW.title IS DISTINCT FROM OLD.title OR
       NEW.description IS DISTINCT FROM OLD.description THEN
      RAISE EXCEPTION 'Cannot modify content of archived profile. Restore first.';
    END IF;
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_prevent_archived_update
BEFORE UPDATE ON csms_profiles
FOR EACH ROW EXECUTE FUNCTION prevent_archived_update();
```

**Lapis 2 — API Validation (Prisma/Backend):**
```typescript
// Di handler PUT /csms-profiles/:id
async function updateProfile(id: string, data: UpdateProfileDto, orgId: string) {
  const profile = await prisma.csmsProfile.findFirst({
    where: { id, organizationId: orgId }
  });
  
  if (!profile) throw new NotFoundError();
  
  // PERBAIKAN: Tolak jika archived ATAU locked
  if (profile.archived) {
    throw new ForbiddenError(
      'PROFILING_ARCHIVED',
      'Profil yang diarsipkan tidak dapat diedit. Pulihkan terlebih dahulu atau buat versi baru.'
    );
  }
  
  if (profile.locked) {
    throw new ForbiddenError('PROFILING_LOCKED', 'Profil terkunci.');
  }
  
  return await prisma.csmsProfile.update({
    where: { id },
    data: { ...data, updatedAt: new Date() }
  });
}
```

## 2. Temuan TINGGI #2: Metadata Audit Pengarsipan Tidak Ada

Ini adalah **temuan paling kritis** untuk aplikasi kepatuhan. Dalam investigasi kecelakaan kerja, pertanyaan pertama pengawas adalah: *"Siapa yang mengubah standar K3, kapan, dan mengapa?"* Tanpa metadata ini, Anda tidak punya jawaban.

### Solusi: Tabel Audit Trail Terpisah (Immutable)

Jangan hanya menambah kolom di tabel `csms_profiles`. Buat tabel terpisah untuk riwayat archive/restore agar **tidak bisa dihapus atau diubah**.

**Skema Database:**
```sql
-- Tabel utama: tambah kolom metadata
ALTER TABLE csms_profiles ADD COLUMN 
  archived_at TIMESTAMP,
  archived_by UUID REFERENCES users(id),
  archive_reason TEXT,
  superseded_by UUID REFERENCES csms_profiles(id),
  restored_at TIMESTAMP,
  restored_by UUID REFERENCES users(id);

-- Tabel audit trail (IMMUTABLE - tidak ada UPDATE/DELETE)
CREATE TABLE csms_profile_archive_history (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  profile_id UUID NOT NULL REFERENCES csms_profiles(id),
  action VARCHAR(20) NOT NULL CHECK (action IN ('ARCHIVED', 'RESTORED')),
  actor_id UUID NOT NULL REFERENCES users(id),
  performed_at TIMESTAMP NOT NULL DEFAULT NOW(),
  reason TEXT,
  superseded_by UUID REFERENCES csms_profiles(id),
  metadata JSONB, -- Untuk menyimpan snapshot konteks (jumlah proyek terpengaruh, dll)
  
  CONSTRAINT unique_profile_action_time UNIQUE (profile_id, performed_at)
);

-- Cegah penghapusan riwayat audit
REVOKE DELETE, UPDATE ON csms_profile_archive_history FROM PUBLIC;
GRANT INSERT, SELECT ON csms_profile_archive_history TO app_role;
```

**Handler Archive dengan Audit Trail:**
```typescript
async function archiveProfile(
  id: string, 
  orgId: string, 
  actorId: string,
  payload: { reason: string; supersededBy?: string }
) {
  return await prisma.$transaction(async (tx) => {
    // 1. Validasi
    const profile = await tx.csmsProfile.findFirst({
      where: { id, organizationId: orgId, builtIn: false }
    });
    if (!profile) throw new NotFoundError();
    if (profile.archived) throw new ConflictError('Sudah diarsipkan');
    
    // 2. Analisis dampak (untuk metadata audit)
    const impact = await analyzeArchiveImpact(tx, id, orgId);
    // { activeProjects: 5, documents: 12, readinessEntries: 34 }
    
    // 3. Validasi versi pengganti jika ada
    if (payload.supersededBy) {
      const replacement = await tx.csmsProfile.findFirst({
        where: { 
          id: payload.supersededBy, 
          organizationId: orgId, 
          archived: false 
        }
      });
      if (!replacement) throw new BadRequestError('Versi pengganti tidak valid');
    }
    
    // 4. Update profil utama
    await tx.csmsProfile.update({
      where: { id },
      data: {
        archived: true,
        archivedAt: new Date(),
        archivedBy: actorId,
        archiveReason: payload.reason,
        supersededBy: payload.supersededBy || null,
      }
    });
    
    // 5. Tulis ke audit trail (IMMUTABLE)
    await tx.csmsProfileArchiveHistory.create({
      data: {
        profileId: id,
        action: 'ARCHIVED',
        actorId,
        reason: payload.reason,
        supersededBy: payload.supersededBy || null,
        metadata: {
          impact,
          snapshotAt: new Date().toISOString(),
        }
      }
    });
    
    return { success: true, impact };
  });
}

// Fungsi serupa untuk restore (action: 'RESTORED')
```

```typescript
// Step 1: Endpoint untuk preview dampak (tanpa mengubah data)
// GET /csms-profiles/:id/archive-impact
async function previewArchiveImpact(profileId: string, orgId: string) {
  const [activeProjects, documents, readinessEntries] = await Promise.all([
    prisma.project.count({
      where: { csmsProfileId: profileId, status: 'ACTIVE' }
    }),
    prisma.generatedDocument.count({
      where: { csmsProfileId: profileId }
    }),
    prisma.readinessEntry.count({
      where: { csmsProfileId: profileId }
    })
  ]);
  
  // Cari versi pengganti yang disarankan (versi terbaru yang aktif)
  const suggestedReplacement = await prisma.csmsProfile.findFirst({
    where: { 
      organizationId: orgId,
      archived: false,
      id: { not: profileId },
      // Asumsi ada field 'baseProfileId' untuk melacak versi
    },
    orderBy: { createdAt: 'desc' }
  });
  
  return {
    activeProjects,
    documents,
    readinessEntries,
    suggestedReplacement,
    hasActiveUsage: activeProjects > 0
  };
}
```

## 5. Temuan RENDAH: Status Eksplisit (DRAFT/ACTIVE/ARCHIVED)

Ini adalah perbaikan struktural yang bagus untuk masa depan, tapi **bisa ditunda** karena kombinasi boolean saat ini sudah berfungsi. Jika Anda ingin melakukannya, berikut skemanya:

```sql
-- Migrasi dari boolean ke enum
ALTER TABLE csms_profiles ADD COLUMN 
  publication_status VARCHAR(20) DEFAULT 'ACTIVE' 
  CHECK (publication_status IN ('DRAFT', 'ACTIVE', 'ARCHIVED'));

-- Migrasi data existing
UPDATE csms_profiles 
SET publication_status = 'ARCHIVED' 
WHERE archived = true;

-- Hapus kolom lama setelah migrasi
ALTER TABLE csms_profiles DROP COLUMN archived;
```

**Rekomendasi saya:** Tunda ini sampai Task #40 selesai, karena ini adalah perubahan skema yang berdampak luas.
