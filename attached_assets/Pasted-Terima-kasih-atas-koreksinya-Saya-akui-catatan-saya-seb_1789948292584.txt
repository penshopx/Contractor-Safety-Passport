### 3. Audit Nilai Spesifik

Cek juga nilai-nilai khusus yang mungkin bermasalah:

```sql
-- Cek nilai kosong atau 'legacy'
SELECT table_name, organization_id, COUNT(*) as count
FROM (
    SELECT 'projects' as table_name, organization_id FROM projects
    UNION ALL
    SELECT 'people', organization_id FROM people
    UNION ALL
    SELECT 'safety_documents', organization_id FROM safety_documents
    -- ... tambahkan tabel lainnya
) all_data
WHERE organization_id IS NULL 
    OR organization_id = ''
    OR organization_id = 'legacy'
    OR organization_id = 'placeholder'
GROUP BY table_name, organization_id
ORDER BY table_name, count DESC;
```

## Panduan Penanganan Data Lama

### Prinsip Utama

**Jangan otomatis menghapus atau memindahkan data** tanpa bukti migrasi yang jelas.

### Langkah Investigasi

Untuk setiap data yatim yang ditemukan:

1. **Cek metadata data**:
   ```sql
   SELECT id, organization_id, created_at, created_by, updated_at
   FROM projects
   WHERE organization_id NOT IN (SELECT id FROM organizations)
   ORDER BY created_at;
   ```

2. **Cek log aktivitas** (jika ada):
   - Siapa yang membuat data ini?
   - Kapan dibuat?
   - Apakah ada context tentang organization yang dimaksud?

3. **Cek relasi dengan data lain**:
   - Apakah data ini terhubung dengan user tertentu?
   - Apakah user tersebut masih aktif di organization mana?

### Opsi Penanganan

**Opsi A: Hapus data yatim**
- Hanya jika data tersebut tidak penting dan tidak ada referensi bisnis
- Dokumentasikan alasan penghapusan

**Opsi B: Assign ke organization yang valid**
- Hanya jika ada bukti jelas siapa pemilik data
- Contoh: user yang membuat data masih aktif di organization tertentu

**Opsi C: Biarkan sementara**
- Jika tidak ada bukti yang cukup
- Tandai dengan flag `needs_review`
- Tangani secara manual setelah investigasi lebih lanjut

## Panduan Foreign Key

### Nama Tabel Aktual

```sql

ALTER TABLE projects
ADD CONSTRAINT fk_projects_organization
FOREIGN KEY (organization_id) 
REFERENCES organizations(id)
ON DELETE RESTRICT
ON UPDATE CASCADE;
```
