## Ringkasan Status

### Task #32 — Katalog harga bersama
**Lulus untuk scope utama**: semua anggota workspace memakai katalog server organisasi yang sama, dengan isolasi organisasi dan kontrol akses yang ditegakkan di API.

**Risiko tersisa yang tercatat**:
1. Impor katalog lokal belum idempoten (respons hilang → duplikasi saat retry)
2. Tidak ada deteksi konflik atau review migrasi antar perangkat
3. Edit katalog belum memakai optimistic concurrency (last-write-wins)
4. Belum ada cache offline persisten
5. Belum ada versioning katalog dan audit trail perubahan

### Task #33 — Snapshot harga draft lama
**Fungsi snapshot diterima**: draft menyimpan salinan nilai (harga, wilayah, sumber, tanggal, metadata), sehingga perubahan katalog tidak mempengaruhi BOQ lama.

**Verifikasi server belum sepenuhnya hijau**:
- 3 test gagal, tetapi bukan karena perilaku snapshot salah
- 2 kegagalan karena asumsi pengujian rapuh (urutan item dan format `priceUpdatedAt` ISO vs `YYYY-MM-DD`)
- 1 kegagalan karena database tes bersama — sudah tercakup Task #60

**Catatan**: Snapshot tidak menyimpan `catalogVersion` eksplisit, sehingga user belum bisa melihat "harga ini dari katalog versi X" atau membandingkan dengan versi terbaru. Belum ada mekanisme refresh harga terkontrol.
